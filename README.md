# Travel Planner Chatbot

## Project Overview
The Travel Planner Chatbot is an AI-powered application that helps users plan their trips by generating personalized travel suggestions based on their preferences and requirements.

## Technologies Used
- Python
- Streamlit
- Groq API
- Large Language Model (LLM)
- Python libraries

## Features
- Interactive chatbot interface
- AI-generated travel suggestions
- Personalized travel planning
- Natural language interaction

## Installation

1. Clone the repository.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Create a `.env` file and add your own Groq API key.
4. Run the application:

```bash
streamlit run app.py
```
